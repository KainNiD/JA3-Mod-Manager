# JA3 Mod Manager
Made by KainNiD. Independent community utility for Jagged Alliance 3, Windows x64, EN/RU. Current candidate: 1.0.0-rc.2.

Download the Windows-x64 ZIP from Releases, extract the entire package into a writable folder outside the game and Workshop, then start JA3 Mod Manager.exe. Read Help before configuring mods. WebView2 Runtime is required; separate Python installation is not needed.

The GitHub/Steam build requires the JA3 Mod Manager companion downloaded through Steam Workshop. This is a local presence requirement, not DRM. Workshop carries only the in-game introduction/download link, not the external program. The Workshop link and download destination will be added after publication; no links are claimed live in this preparation.
